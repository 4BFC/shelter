# README 배포 사용자 중심 정리

상태: 반영 완료. 최초 검토: 2026-11-02. 구성 수정: 2026-11-03.

## 목적

README는 제품을 내려받아 실행하는 사용자를 위한 문서입니다. 첫 화면에서 제품을 알아보고, 설치와 사용을 시작하며, 실행 결과를 이해할 수 있어야 합니다. 개발 배경이나 내부 구조를 설명하는 역할은 별도 문서가 맡습니다.

## 최종 구성

1. Shelter ASCII 로고와 짧은 제품 소개
2. 지원 환경, 언어 전환, 향후 실행 화면 캡처를 넣을 위치
3. 설치: 지원 조건, 다운로드, 실행, macOS 보안 확인
4. 사용법: 결과 읽기, 설치 후 설정, 미리보기와 상태 확인
5. 문서 링크와 라이선스

목차는 스펙·설치·사용법·문서·라이선스의 다섯 항목으로 구성합니다. 스펙은 기존 기술 라벨을 사용하는 간결한 표로 보여주고, 상세 정책은 기술 사양 문서로 연결합니다. 체크섬 확인과 설치 후 계정 설정은 펼쳐보는 안내로 제공합니다. 실제 캡처가 준비되기 전에는 빈 이미지나 가상 화면을 넣지 않습니다.

## 문서 배치

- **README:** 사용자에게 필요한 제품 소개, 스펙 표, 설치와 사용법. 영어·한국어·일본어를 같은 구조로 유지합니다.
- **기술 사양:** [영어](../specification.md), [한국어](../specification.ko.md), [일본어](../specification.jp.md). 제품 구성, 설치 대상과 버전 정책, 기술 선택, 개발 계획, 저장소 구조, 전체 옵션과 종료 코드의 참조 문서입니다.
- **CONTRIBUTING:** 저장소에서 실행하는 방법, 빌드, 테스트, 기여와 배포 절차. 이동한 사양과 저장소 구조는 기술 사양 문서로 연결합니다.

README에서 슬로건, 도구를 화살표로 나열한 설치 순서, 배경, 제품 구성, 중복된 고정 설치 스펙 설명, 장문의 기술 방향, 개발 계획과 저장소 트리를 제거했습니다. 기술 라벨 표는 README에 유지합니다. 개발용 자료는 삭제하지 않고 기술 사양으로 이동했습니다.

## 배포 안내 원칙

- 다운로드는 Releases 목록으로 연결하고 설치 파일이 게시된 경우의 절차임을 명시합니다. 파일이 없으면 소스 빌드 안내로 연결합니다.
- 실제 제공되는 설치기의 명령을 안내합니다. 미구현 정식 CLI 명령이나 배포 경로를 만들지 않습니다.
- 현재 프로토타입임을 배지로 표시합니다. 새 Mac 설치, 브라우저 다운로드와 Finder 실행 등의 검증 현황은 개발 문서에서 관리하고 README에는 넣지 않습니다.
- 이번 변경은 문서에 한정합니다. 설치기의 출력, 릴리스 태그와 배포 파일은 변경하지 않습니다.

## 확인

- 문서 11개의 상대 링크와 제목 앵커, Bash 예시 구문, 세 언어 명령 일치 검사를 통과했습니다.
- README의 제품명과 ASCII 로고는 세 언어 모두 Shelter로 통일합니다. 실행 예시의 파일명은 실제 배포 파일명(`Shelter Lite.command`, `shelter-lite-macos.*`)을 유지합니다.
- `git diff --check`를 통과했습니다.
- 실제 설치와 GitHub 배포 여부는 이번 문서 작업에서 검증하지 않습니다. 이전 GitHub 조회도 연결 오류로 완료하지 못했습니다.
